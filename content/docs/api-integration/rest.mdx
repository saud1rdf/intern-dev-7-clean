## Introduction

REST (Representational State Transfer) is an architectural style for designing networked applications. Introduced by Roy Fielding in his 2000 doctoral dissertation, REST has become the dominant paradigm for building web APIs. RESTful APIs use HTTP protocols to communicate, making them simple, scalable, and widely supported by virtually every programming language and platform.

The core philosophy of REST is based on resources - everything in a REST API is represented as a resource that can be identified, created, read, updated, or deleted. These operations map directly to HTTP methods: GET for reading, POST for creating, PUT/PATCH for updating, and DELETE for removing resources.

Understanding REST is essential for modern web development because most web services and APIs follow REST principles. Whether you're integrating with third-party services, building a backend for your application, or designing microservices, REST provides a standardized, predictable approach to API design.

## When to Use REST APIs

REST APIs are appropriate for a wide range of scenarios in modern web development and integration.

### Mobile and Web Applications

REST is ideal for mobile and web applications that need to communicate with backend servers. The stateless nature of REST makes it perfect for applications that may have intermittent connectivity or need to scale horizontally across multiple servers.

### Microservices Architecture

In microservices architectures, different services communicate through APIs. REST's simplicity and widespread support make it a natural choice for inter-service communication, though alternatives like gRPC may be preferred for performance-critical internal communication.

### Third-Party Integrations

Most third-party services (payment processors, social media platforms, cloud services) provide REST APIs for integration. Following REST principles ensures your API integrates seamlessly with these services and follows industry conventions.

### Public APIs

If you're building an API that will be used by external developers, REST is often the best choice due to its familiarity and the vast ecosystem of tools, documentation, and client libraries available.

## Key Concepts

### HTTP Methods

HTTP methods define the actions that can be performed on resources.

```javascript
// GET - Retrieve a resource
async function getUser(userId) {
  const response = await fetch(`https://api.example.com/users/${userId}`);
  
  if (!response.ok) {
    throw new Error(`HTTP error! status: ${response.status}`);
  }
  
  return response.json();
}

// POST - Create a new resource
async function createUser(userData) {
  const response = await fetch('https://api.example.com/users', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
    },
    body: JSON.stringify(userData),
  });
  
  if (!response.ok) {
    const error = await response.json();
    throw new Error(error.message);
  }
  
  return response.json();
}

// PUT - Replace a resource entirely
async function updateUser(userId, userData) {
  const response = await fetch(`https://api.example.com/users/${userId}`, {
    method: 'PUT',
    headers: {
      'Content-Type': 'application/json',
    },
    body: JSON.stringify(userData),
  });
  
  return response.json();
}

// PATCH - Partially update a resource
async function patchUser(userId, updates) {
  const response = await fetch(`https://api.example.com/users/${userId}`, {
    method: 'PATCH',
    headers: {
      'Content-Type': 'application/json',
    },
    body: JSON.stringify(updates),
  });
  
  return response.json();
}

// DELETE - Remove a resource
async function deleteUser(userId) {
  const response = await fetch(`https://api.example.com/users/${userId}`, {
    method: 'DELETE',
  });
  
  if (response.status === 204) {
    return null; // No content
  }
  
  return response.json();
}
```

### HTTP Status Codes

Status codes indicate the result of an HTTP request.

```javascript
// 2xx Success
const CREATED = 201;      // Resource created successfully
const ACCEPTED = 202;     // Request accepted for processing
const NO_CONTENT = 204;   // Successful with no content to return

// 3xx Redirection
const MOVED_PERMANENTLY = 301;
const FOUND = 302;
const NOT_MODIFIED = 304;

// 4xx Client Error
const BAD_REQUEST = 400;
const UNAUTHORIZED = 401;
const FORBIDDEN = 403;
const NOT_FOUND = 404;
const CONFLICT = 409;
const UNPROCESSABLE_ENTITY = 422;
const TOO_MANY_REQUESTS = 429;

// 5xx Server Error
const INTERNAL_SERVER_ERROR = 500;
const BAD_GATEWAY = 502;
const SERVICE_UNAVAILABLE = 503;

// Handling different status codes
async function handleApiResponse(response) {
  if (response.ok) {
    // For 2xx responses
    if (response.status === 204) {
      return null;
    }
    return response.json();
  }
  
  // Handle errors based on status code
  switch (response.status) {
    case 401:
      throw new AuthenticationError('Please log in again');
    case 403:
      throw new AuthorizationError('You do not have permission');
    case 404:
      throw new NotFoundError('Resource not found');
    case 429:
      const retryAfter = response.headers.get('Retry-After');
      throw new RateLimitError('Too many requests', retryAfter);
    case 500:
      throw new ServerError('Something went wrong');
    default:
      const errorData = await response.json().catch(() => ({}));
      throw new ApiError(errorData.message || 'Unknown error');
  }
}
```

### URL Structure

REST APIs use clear, hierarchical URL structures.

```javascript
// Resource-based URLs
// GET /users - List all users
// GET /users/:id - Get specific user
// POST /users - Create user
// PUT /users/:id - Update user
// DELETE /users/:id - Delete user

// Nested resources
// GET /users/:userId/posts - Get user's posts
// GET /users/:userId/posts/:postId - Get specific post
// POST /users/:userId/posts - Create post for user

// Query parameters for filtering, pagination, sorting
// GET /users?role=admin&sort=name
// GET /posts?page=2&limit=20
// GET /posts?status=published&author=:id
// GET /search?q=keyword&type=article

// Building URLs safely
const baseUrl = 'https://api.example.com';
const userId = '123';
const postId = '456';

// Manual concatenation (be careful of special characters)
const url = baseUrl + '/users/' + userId + '/posts/' + postId;

// URLSearchParams for query strings
const params = new URLSearchParams({
  page: '2',
  limit: '20',
  sort: '-createdAt',
  status: 'published'
});
const queryUrl = `${baseUrl}/posts?${params}`;
```

### Request and Response Patterns

```javascript
// Consistent API client setup
class ApiClient {
  constructor(baseUrl, defaultHeaders = {}) {
    this.baseUrl = baseUrl;
    this.defaultHeaders = {
      'Content-Type': 'application/json',
      ...defaultHeaders,
    };
  }
  
  async request(method, path, options = {}) {
    const url = new URL(path, this.baseUrl);
    
    // Add query parameters
    if (options.params) {
      Object.entries(options.params).forEach(([key, value]) => {
        if (value !== undefined && value !== null) {
          url.searchParams.append(key, String(value));
        }
      });
    }
    
    const response = await fetch(url.toString(), {
      method,
      headers: {
        ...this.defaultHeaders,
        ...options.headers,
      },
      body: options.body ? JSON.stringify(options.body) : undefined,
    });
    
    return this.handleResponse(response);
  }
  
  get(path, options) {
    return this.request('GET', path, options);
  }
  
  post(path, body, options) {
    return this.request('POST', path, { ...options, body });
  }
  
  put(path, body, options) {
    return this.request('PUT', path, { ...options, body });
  }
  
  patch(path, body, options) {
    return this.request('PATCH', path, { ...options, body });
  }
  
  delete(path, options) {
    return this.request('DELETE', path, options);
  }
  
  async handleResponse(response) {
    const data = response.status === 204 
      ? null 
      : await response.json().catch(() => null);
    
    if (!response.ok) {
      throw new ApiError(
        data?.message || `HTTP ${response.status}`,
        response.status,
        data
      );
    }
    
    return data;
  }
}

// Using the API client
const api = new ApiClient('https://api.example.com', {
  'Authorization': `Bearer ${token}`,
});

// Get list with pagination
const { data: users, pagination } = await api.get('/users', {
  params: { page: 1, limit: 10 },
});

// Create resource
const newUser = await api.post('/users', {
  name: 'John Doe',
  email: 'john@example.com',
});
```

### Authentication

```javascript
// API Key authentication
const apiKeyClient = new ApiClient('https://api.example.com', {
  'X-API-Key': 'your-api-key',
});

// Bearer token authentication
const tokenClient = new ApiClient('https://api.example.com', {
  'Authorization': `Bearer ${accessToken}`,
});

// Basic authentication (not recommended for production)
const basicClient = new ApiClient('https://api.example.com', {
  'Authorization': `Basic ${btoa('username:password')}`,
});

// OAuth 2.0 flow example
async function refreshAccessToken(refreshToken) {
  const response = await fetch('https://auth.example.com/oauth/token', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/x-www-form-urlencoded',
    },
    body: new URLSearchParams({
      grant_type: 'refresh_token',
      refresh_token: refreshToken,
      client_id: process.env.CLIENT_ID,
      client_secret: process.env.CLIENT_SECRET,
    }),
  });
  
  if (!response.ok) {
    throw new Error('Failed to refresh token');
  }
  
  return response.json();
}
```

## Full Example: Complete API Service Layer

```typescript
// services/api.ts - Comprehensive API service

import ApiClient from '@/lib/api-client';

export interface User {
  id: string;
  name: string;
  email: string;
  role: 'admin' | 'user';
  createdAt: string;
  updatedAt: string;
}

export interface CreateUserDto {
  name: string;
  email: string;
  password: string;
  role?: 'admin' | 'user';
}

export interface UpdateUserDto {
  name?: string;
  email?: string;
  role?: 'admin' | 'user';
}

export interface PaginatedResponse<T> {
  data: T[];
  meta: {
    total: number;
    page: number;
    limit: number;
    totalPages: number;
  };
}

export interface ApiError {
  message: string;
  code?: string;
  details?: Record<string, string[]>;
}

class UserService {
  private client: ApiClient;
  
  constructor() {
    this.client = new ApiClient(process.env.NEXT_PUBLIC_API_URL);
  }
  
  async getUsers(
    options: {
      page?: number;
      limit?: number;
      sort?: string;
      role?: string;
      search?: string;
    } = {}
  ): Promise<PaginatedResponse<User>> {
    return this.client.get('/users', {
      params: {
        page: options.page || 1,
        limit: options.limit || 10,
        sort: options.sort || '-createdAt',
        role: options.role,
        search: options.search,
      },
    });
  }
  
  async getUserById(id: string): Promise<User> {
    return this.client.get(`/users/${id}`);
  }
  
  async createUser(data: CreateUserDto): Promise<User> {
    return this.client.post('/users', data);
  }
  
  async updateUser(id: string, data: UpdateUserDto): Promise<User> {
    return this.client.patch(`/users/${id}`, data);
  }
  
  async deleteUser(id: string): Promise<void> {
    await this.client.delete(`/users/${id}`);
  }
  
  async getUserPosts(userId: string): Promise<Post[]> {
    return this.client.get(`/users/${userId}/posts`);
  }
  
  async getCurrentUser(): Promise<User> {
    return this.client.get('/users/me');
  }
  
  async updateProfile(data: UpdateUserDto): Promise<User> {
    return this.client.patch('/users/me', data);
  }
  
  async changePassword(currentPassword: string, newPassword: string): Promise<void> {
    await this.client.post('/users/me/password', {
      currentPassword,
      newPassword,
    });
  }
}

export const userService = new UserService();

// Custom React hook for using the service
import { useState, useCallback } from 'react';

export function useUsers(options: { page?: number } = {}) {
  const [users, setUsers] = useState<User[]>([]);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState<Error | null>(null);
  const [pagination, setPagination] = useState({
    total: 0,
    page: 1,
    limit: 10,
    totalPages: 0,
  });
  
  const fetchUsers = useCallback(async () => {
    setLoading(true);
    setError(null);
    
    try {
      const result = await userService.getUsers({ page: options.page });
      setUsers(result.data);
      setPagination(result.meta);
    } catch (err) {
      setError(err instanceof Error ? err : new Error('Unknown error'));
    } finally {
      setLoading(false);
    }
  }, [options.page]);
  
  const createUser = useCallback(async (data: CreateUserDto) => {
    setLoading(true);
    try {
      await userService.createUser(data);
      await fetchUsers();
    } catch (err) {
      setError(err instanceof Error ? err : new Error('Unknown error'));
      throw err;
    } finally {
      setLoading(false);
    }
  }, [fetchUsers]);
  
  const deleteUser = useCallback(async (id: string) => {
    setLoading(true);
    try {
      await userService.deleteUser(id);
      setUsers(prev => prev.filter(u => u.id !== id));
    } catch (err) {
      setError(err instanceof Error ? err : new Error('Unknown error'));
      throw err;
    } finally {
      setLoading(false);
    }
  }, []);
  
  return {
    users,
    loading,
    error,
    pagination,
    fetchUsers,
    createUser,
    deleteUser,
  };
}
```

## Common Mistakes

### Not Handling Network Errors

```javascript
// ❌ WRONG - No error handling
async function fetchData() {
  const response = await fetch('/api/data');
  return response.json();
}

// ✅ CORRECT - Comprehensive error handling
async function fetchData() {
  try {
    const response = await fetch('/api/data');
    
    // Check for HTTP errors
    if (!response.ok) {
      throw new ApiError(`HTTP ${response.status}`, response.status);
    }
    
    // Handle empty responses
    const contentType = response.headers.get('content-type');
    if (!contentType || !contentType.includes('application/json')) {
      throw new ApiError('Invalid response format', 500);
    }
    
    return response.json();
  } catch (error) {
    if (error instanceof TypeError && error.message === 'Failed to fetch') {
      throw new NetworkError('Unable to connect to server');
    }
    throw error;
  }
}
```

### Not Implementing Proper Pagination

```javascript
// ❌ WRONG - Loading all data
async function getAllItems() {
  const response = await fetch('/api/items');
  return response.json();
}

// ✅ CORRECT - Paginated fetching
async function getAllItems() {
  let allItems = [];
  let page = 1;
  const limit = 100;
  
  while (true) {
    const response = await fetch(`/api/items?page=${page}&limit=${limit}`);
    const data = await response.json();
    
    allItems = allItems.concat(data.items);
    
    if (page >= data.meta.totalPages) {
      break;
    }
    
    page++;
  }
  
  return allItems;
}
```

### Not Using Proper HTTP Methods

```javascript
// ❌ WRONG - Using POST for everything
async function getUser(id) {
  return fetch('/api/user', {
    method: 'POST',
    body: JSON.stringify({ id }),
  });
}

// ✅ CORRECT - Using appropriate methods
async function getUser(id) {
  return fetch(`/api/users/${id}`);
}
```
