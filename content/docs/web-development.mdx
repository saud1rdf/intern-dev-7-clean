## 🌱 Fundamentals & Basics (الأساسيات للمبتدئين)

### English
Web development is the practice of building websites and web apps. As an intern, focus on **the core trio**:
* **HTML**: structure (what’s on the page)
* **CSS**: style (how it looks)
* **JavaScript**: behavior (how it works)

### What you should learn first
1. HTML semantic tags (header, nav, main, section)
2. CSS layout (flexbox + grid)
3. JavaScript basics (variables, functions, DOM)
4. Fetching data (APIs)
5. Debugging (DevTools)

### Mini practice task
Build a simple page:
* Header + navbar
* Cards section (3 cards)
* Button that changes text when clicked

```html
<button id="btn">Click me</button>
<script>
  document.getElementById("btn").addEventListener("click", () => {
    document.getElementById("btn").textContent = "Done ✅";
  });
</script>
