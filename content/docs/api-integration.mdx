## 🌱 Fundamentals

### REST API Fundamentals

**Beginner · 10 min**

REST APIs allow applications to communicate over HTTP using standard methods such as GET, POST, PUT, PATCH, and DELETE.

### Example

```javascript
async function fetchUserData(userId) {
  const response = await fetch(
    `https://api.example.com/users/${userId}`
  );

  const data = await response.json();

  return data;
}

const user = await fetchUserData(123);

console.log(user);
```

This example sends an HTTP request, converts the JSON response into a JavaScript object, and returns the user data.

### Introduction to GraphQL

**Intermediate · 10 min**

GraphQL allows clients to request exactly the fields they need from the server.

### Example

```javascript
const GET_USER = `
query GetUser($id: ID!) {

  user(id: $id) {

    name

    email

    posts {

      title

      content

    }

  }

}
`;

const { data } = await client.query({
  query: GET_USER,
  variables: {
    id: "123",
  },
});
```

Unlike REST, GraphQL returns only the requested fields, reducing unnecessary data transfer and improving flexibility.
