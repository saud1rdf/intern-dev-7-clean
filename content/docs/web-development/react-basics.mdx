# React High-Performance State Architecture

## Overview

React uses a virtual DOM system to efficiently update interfaces when state changes.

However, poor state management can cause:

1. Unnecessary component re-renders.
2. Lost application state after page refresh.
3. Difficult-to-debug hook dependency issues.

---

# Key Concepts

## Reconciliation Optimization

React compares previous and new UI trees to determine what needs updating.

Optimization techniques include:

- React.memo
- useMemo
- useCallback
- Proper component boundaries

---

## State Categories

React applications usually contain different types of state:

| State Type | Example Tools | Purpose |
|---|---|---|
| Local State | useState, useReducer | Component-specific data |
| Global State | Context, Zustand, Redux | Shared application data |
| Server State | TanStack Query, SWR | API data caching |
| URL State | Search Params | Shareable navigation state |

# Split Context Pattern

Separating state and dispatch contexts prevents unnecessary re-renders.

```tsx
"use client";

import React, {
  createContext,
  useContext,
  useReducer
} from "react";


interface AppState {
  theme: "light" | "dark";
  sidebarOpen: boolean;
}


type Action =
  | {
      type: "TOGGLE_THEME";
    }
  | {
      type: "SET_SIDEBAR";
      payload: boolean;
    };


const initialState: AppState = {
  theme: "light",
  sidebarOpen: false,
};


const StateContext =
  createContext<AppState | undefined>(undefined);


const DispatchContext =
  createContext<React.Dispatch<Action> | undefined>(
    undefined
  );


function reducer(
  state: AppState,
  action: Action
): AppState {

  switch(action.type) {

    case "TOGGLE_THEME":

      return {
        ...state,
        theme:
          state.theme === "light"
            ? "dark"
            : "light",
      };


    case "SET_SIDEBAR":

      return {
        ...state,
        sidebarOpen: action.payload,
      };


    default:

      return state;
  }
}


export function AppProvider({
  children
}: {
  children: React.ReactNode;
}) {

  const [state, dispatch] =
    useReducer(
      reducer,
      initialState
    );


  return (

    <StateContext.Provider value={state}>

      <DispatchContext.Provider value={dispatch}>

        {children}

      </DispatchContext.Provider>

    </StateContext.Provider>

  );
}
URL Query State Hook

URL state allows users to share links while preserving filters and navigation.

"use client";

import {
  useRouter,
  useSearchParams,
  usePathname
} from "next/navigation";

import {
  useCallback,
  useMemo
} from "react";


export function useURLQueryState<T extends string>(
  key: string,
  defaultValue: T
): [T, (value:T)=>void] {


  const router = useRouter();

  const params = useSearchParams();

  const pathname = usePathname();



  const value = useMemo(() => {

    return (
      params.get(key) as T
    ) || defaultValue;

  }, [
    params,
    key,
    defaultValue
  ]);



  const updateValue =
    useCallback(
      (newValue:T)=>{

        const updated =
          new URLSearchParams(
            params.toString()
          );


        if(newValue === defaultValue){

          updated.delete(key);

        } else {

          updated.set(
            key,
            newValue
          );

        }


        router.push(
          `${pathname}?${updated}`,
          {
            scroll:false
          }
        );

      },
      [
        router,
        params,
        pathname,
        key,
        defaultValue
      ]
    );


  return [
    value,
    updateValue
  ];
}
Best Practices
Never Mutate State Directly

Bad:

state.items.push(item);

Good:

setItems([
  ...items,
  item
]);
Keep State as Low as Possible

Store state close to the components that need it.

Avoid placing every piece of data inside global providers.

Optimize Context Values

Use memoization when passing large objects through Context.
