## Introduction

HTML (HyperText Markup Language) is the foundation of the World Wide Web. It provides the structural skeleton for all web pages, defining the meaning and organization of content. First proposed by Tim Berners-Lee in 1989 and standardized by the W3C, HTML has evolved through multiple versions to become the powerful markup language we use today.

HTML5, the current major version, introduced significant new features including semantic elements, native multimedia support through video and audio tags, canvas for graphics, and APIs for offline storage and geolocation. These additions transformed HTML from a simple document markup language into a platform for building complex web applications without relying heavily on plugins or external technologies.

Understanding HTML is essential for every web developer because it forms the basis upon which CSS styling and JavaScript interactivity are built. Even in modern frameworks like React and Next.js, developers must understand HTML concepts to create effective, accessible, and well-structured applications. The principles of semantic markup, proper nesting, and accessibility are universal skills that transcend any particular framework or library.

## When to Use HTML

HTML is the universal language of the web and is used in virtually every web development scenario. Understanding when and how to apply HTML effectively is crucial for building quality web experiences.

### Document Structure

Every web page requires HTML to define its basic structure. From simple landing pages to complex web applications, HTML provides the semantic foundation that communicates the purpose and hierarchy of content to browsers, search engines, and assistive technologies.

### Form Creation

HTML forms are essential for collecting user input, whether it's a simple contact form, a complex checkout process, or a search interface. HTML5 introduced many new input types and attributes that make form creation more powerful and user-friendly.

### Content Semantics

Using semantic HTML elements correctly helps search engines understand your content, improves accessibility for screen reader users, and makes your code more maintainable. Semantic elements like article, section, nav, and aside communicate the meaning of content beyond just its visual appearance.

### Multimedia Integration

HTML5 provides native support for embedding images, audio, video, and graphics without requiring third-party plugins. This native support is faster, more accessible, and works across all modern devices and browsers.

## Key Concepts

### Document Structure

Every HTML document follows a standard structure that browsers expect. This structure includes the DOCTYPE declaration, html, head, and body elements.

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="A brief description of the page">
    <title>Page Title</title>
    <link rel="stylesheet" href="styles.css">
    <link rel="icon" href="favicon.ico">
  </head>
  <body>
    <header>
      <nav>
        <ul>
          <li><a href="/">Home</a></li>
          <li><a href="/about">About</a></li>
          <li><a href="/contact">Contact</a></li>
        </ul>
      </nav>
    </header>
    
    <main>
      <article>
        <h1>Main Heading</h1>
        <p>Paragraph text goes here.</p>
      </article>
      
      <aside>
        <h2>Related Content</h2>
        <p>Sidebar content.</p>
      </aside>
    </main>
    
    <footer>
      <p>&copy; 2024 Company Name. All rights reserved.</p>
    </footer>
    
    <script src="app.js"></script>
  </body>
</html>
```

### Semantic Elements

HTML5 introduced semantic elements that describe their meaning to both browsers and developers. Using these elements improves accessibility and SEO.

```html
<!-- Header section - typically contains navigation or introductory content -->
<header>
  <h1>Website Title</h1>
  <nav>
    <a href="#home">Home</a>
    <a href="#products">Products</a>
    <a href="#about">About</a>
  </nav>
</header>

<!-- Main content - the primary content of the document -->
<main>
  <!-- Article - self-contained content -->
  <article>
    <header>
      <h2>Article Title</h2>
      <time datetime="2024-01-15">January 15, 2024</time>
    </header>
    <p>Article content here.</p>
    <footer>
      <p>Author: John Doe</p>
    </footer>
  </article>
  
  <!-- Section - thematic grouping of content -->
  <section>
    <h2>Features</h2>
    <p>Description of features.</p>
  </section>
</main>

<!-- Navigation - navigation links -->
<nav aria-label="Main navigation">
  <ul>
    <li><a href="#getting-started">Getting Started</a></li>
    <li><a href="#tutorials">Tutorials</a></li>
    <li><a href="#reference">Reference</a></li>
  </ul>
</nav>

<!-- Aside - tangential or related content -->
<aside>
  <h3>Related Articles</h3>
  <ul>
    <li><a href="#article1">Article 1</a></li>
    <li><a href="#article2">Article 2</a></li>
  </ul>
</aside>

<!-- Footer - footer for the document or section -->
<footer>
  <nav aria-label="Footer navigation">
    <a href="/privacy">Privacy Policy</a>
    <a href="/terms">Terms of Service</a>
  </nav>
</footer>
```

HTML forms are essential for user interaction. HTML5 introduced many new input types and attributes.

### Tables

HTML tables are used for displaying tabular data. They should not be used for layout purposes.

```html
<table>
  <caption>Monthly Sales Report</caption>
  <thead>
    <tr>
      <th scope="col">Month</th>
      <th scope="col">Revenue</th>
      <th scope="col">Expenses</th>
      <th scope="col">Profit</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">January</th>
      <td>$50,000</td>
      <td>$30,000</td>
      <td>$20,000</td>
    </tr>
    <tr>
      <th scope="row">February</th>
      <td>$55,000</td>
      <td>$32,000</td>
      <td>$23,000</td>
    </tr>
    <tr>
      <th scope="row">March</th>
      <td>$60,000</td>

  <tfoot>
    <tr>
      <th scope="row">Total</th>

      <td>$97,000</td>
      <td>$68,000</td>
    </tr>
  </tfoot>
```

### Multimedia

HTML5 provides native support for embedding media content.

```html
<!-- Image with responsive attributes -->
<img 
  src="image.jpg" 
  srcset="
    image-320w.jpg 320w,
    image-640w.jpg 640w,
    image-1024w.jpg 1024w
  "
  sizes="(max-width: 640px) 100vw, (max-width: 1024px) 50vw, 33vw"
  alt="Description of the image for accessibility"
  loading="lazy"
  width="1024"
  height="768"
>

<!-- Audio player -->
<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
  <source src="audio.ogg" type="audio/ogg">
  Your browser does not support the audio element.
</audio>

<!-- Video player -->
<video 
  controls 
  width="640" 
  height="360"
  poster="video-poster.jpg"
  preload="metadata"
>
  <source src="video.mp4" type="video/mp4">
  <source src="video.webm" type="video/webm">
  <track 
    kind="captions" 
    src="captions.vtt" 
    srclang="en" 
    label="English"
    default
  >
  Your browser does not support the video element.
</video>

<!-- Figure with caption -->
<figure>
  <img src="chart.png" alt="Sales chart showing growth">
  <figcaption>
    Figure 1: Quarterly sales growth from 2020 to 2024.
  </figcaption>
</figure>
```

### Accessibility Attributes

HTML provides attributes to improve accessibility for users with disabilities.

```html
<!-- Skip link for keyboard users -->
<a href="#main-content" class="skip-link">Skip to main content</a>

<!-- ARIA labels for complex interactive elements -->
<div 
  role="combobox" 
  aria-expanded="false" 
  aria-controls="listbox" 
  aria-label="Select a programming language"
>
  <input type="text" aria-autocomplete="list" aria-controls="listbox">
</div>

<!-- Live region for dynamic content announcements -->
<div 
  role="status" 
  aria-live="polite" 
  aria-atomic="true"
>
  <p>Form submitted successfully!</p>
</div>

<!-- Accessible data visualization -->
<figure>
  <figcaption>Sales Performance Chart</figcaption>
  <!-- Chart implementation -->
</figure>

<!-- Proper heading hierarchy -->
<main id="main-content">
  <h1>Main Page Title</h1>
  <section>
    <h2>Section Title</h2>
    <article>
      <h3>Article Title</h3>
      <h4>Subsection</h4>
    </article>
  </section>
</main>
```

## Common Mistakes

### Using Non-Semantic Elements for Layout

Using div elements for everything instead of semantic elements makes code harder to maintain and less accessible.

```html
<!-- ❌ WRONG - Non-semantic structure -->
<div class="header">
  <div class="nav">
    <div class="logo"></div>
    <div class="menu">
      <div class="item"></div>
    </div>
  </div>
</div>
<div class="main">
  <div class="content"></div>
  <div class="sidebar"></div>
</div>
<div class="footer"></div>

<!-- ✅ CORRECT - Semantic structure -->
<header>
  <nav>...</nav>
</header>
<main>
  <article>...</article>
  <aside>...</aside>
</main>
<footer>...</footer>
```

### Missing Alt Text or Using Placeholder Text

Images without proper alt text are inaccessible to screen reader users and hurt SEO.

```html
<!-- ❌ WRONG - Missing or placeholder alt text -->
<img src="product.jpg" alt="image">
<img src="chart.png" alt="">

<!-- ✅ CORRECT - Descriptive alt text -->
<img src="product.jpg" alt="Silver MacBook Pro with Retina display on wooden desk">
<img src="chart.png" alt="Bar chart showing 40% increase in Q4 revenue from $50K to $70K">
```

### Improper Heading Hierarchy

Skipping heading levels or having multiple h1 elements confuses screen readers and search engines.

```html
<!-- ❌ WRONG - Broken heading hierarchy -->
<h1>Main Title</h1>
<h3>Section (skipped h2)</h3>
<h1>Another h1</h1>

<!-- ✅ CORRECT - Proper hierarchy -->
<h1>Main Title</h1>
<h2>Section</h2>
<h3>Subsection</h3>
```
