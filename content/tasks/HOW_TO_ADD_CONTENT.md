# دليل إضافة المحتوى - How to Add Content

## كيفية إضافة محتوى جديد

### الخطوات:

1. **أنشئ ملف Markdown جديد** في مجلد `content/tasks/`
   - يجب أن يكون اسم الملف باللغة الإنجليزية
   - استخدم الشرطات (hyphens) بدلاً من المسافات
   - مثال: `my-new-task.md`

2. **ابدأ الملف بعنوان رئيسي**
   - السطر الأول يجب أن يبدأ بـ `#` متبوعاً بالعنوان
   - مثال: `# عنوان المهمة - Task Title`

3. **اكتب المحتوى باستخدام Markdown**
   - استخدم `##` للعناوين الفرعية
   - استخدم `-` أو `*` للقوائم
   - يمكنك استخدام **نص عريض** و *نص مائل*

4. **احفظ الملف**
   - بعد الحفظ، سيظهر المحتوى تلقائياً في الموقع على `/tasks/اسم-الملف`

### مثال على هيكل الملف:

```markdown
# عنوان المهمة - Task Title

## نظرة عامة - Overview

وصف المهمة هنا...

## المتطلبات - Requirements

1. المتطلب الأول
2. المتطلب الثاني

## النتائج المتوقعة - Expected Deliverables

- النتيجة الأولى
- النتيجة الثانية
```

### ملاحظات مهمة:

- اسم الملف سيصبح جزءاً من رابط الصفحة (URL slug)
- العنوان في السطر الأول سيظهر في قائمة المهام
- يمكنك كتابة المحتوى بالعربية أو الإنجليزية أو كليهما
- استخدم تنسيق Markdown القياسي

### أمثلة على أسماء ملفات جيدة:

- `react-hooks-advanced.md`
- `nodejs-async-patterns.md`
- `database-optimization.md`
- `api-design-principles.md`

## How to Add New Content

### Steps:

1. **Create a new Markdown file** in the `content/tasks/` folder
   - File name should be in English
   - Use hyphens instead of spaces
   - Example: `my-new-task.md`

2. **Start the file with a main heading**
   - First line should start with `#` followed by the title
   - Example: `# Task Title`

3. **Write content using Markdown**
   - Use `##` for subheadings
   - Use `-` or `*` for lists
   - You can use **bold** and *italic* text

4. **Save the file**
   - After saving, content will automatically appear on the site at `/tasks/filename`

### Example File Structure:

```markdown
# Task Title

## Overview

Description of the task here...

## Requirements

1. First requirement
2. Second requirement

## Expected Deliverables

- First deliverable
- Second deliverable
```

### Important Notes:

- The filename will become part of the page URL (slug)
- The title in the first line will appear in the tasks list
- You can write content in Arabic, English, or both
- Use standard Markdown formatting

### Examples of Good Filenames:

- `react-hooks-advanced.md`
- `nodejs-async-patterns.md`
- `database-optimization.md`
- `api-design-principles.md`
